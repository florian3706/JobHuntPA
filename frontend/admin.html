With email set up, JobHuntPA can send password reset links, address confirmations, invitations and security notices. Use your email provider's own mail server (SMTP). To keep messages out of spam, set up SPF, DKIM and DMARC for the From address's domain as your provider describes.

    Lets Stripe tell JobHuntPA about payments straight away. Without it, memberships still update when people come back from checkout and every 6 hours.
    The monthly price in Stripe has this lookup key (default jobhunt_monthly). An optional yearly price uses jobhunt_yearly.

    Server key

    The server key protects the keys JobHuntPA keeps for background searches and two-step sign-in. Replacing it moves all of them to a new key and drops the old one. Do it if the data folder or a backup of it may have been copied by someone else. It asks for your password and takes a few seconds.
